# Svidanie Astana

Полноценный сайт для бронирования романтических свиданий, дней рождения и
предложений руки и сердца в панорамном куполе в Астане — с онлайн-бронированием,
предоплатой через Kaspi и отдельной админ-панелью для владельца и менеджеров.

**Сайт:** https://svidanie-site.vercel.app
**Instagram:** [@svidanie.astana](https://www.instagram.com/svidanie.astana/)

## Что умеет

**Публичный сайт**
- Каталог пакетов (свидания, дни рождения, предложения, комбо) с фильтрами по категориям
- Проверка свободных слотов в реальном времени с учётом длительности пакета и времени на подготовку помещения
- Бронирование без регистрации: имя, телефон, дата/время, комментарий
- Онлайн-предоплата 50% через Kaspi (ссылка на оплату + ручное подтверждение менеджером)
- Уведомления о новых заявках и оплатах в Telegram

**Админ-панель** (`/admin.html`)
- Роли: **администратор** (полный доступ) и **менеджер** (только заявки и бронирование)
- Управление пакетами, ценами, галереей и настройками сайта
- Список заявок со сменой статуса и подтверждением оплаты
- Отдельный кабинет менеджера: посмотреть свободное время и оформить бронь за клиента прямо во время звонка
- Управление сотрудниками (добавление/удаление доступа) без похода в Supabase Dashboard

## Стек

- **Frontend** — статический HTML/CSS/vanilla JS, без сборки
- **Backend** — [NestJS](https://nestjs.com/) (TypeScript), REST API
- **База данных** — PostgreSQL (Supabase), Row Level Security для разделения прав admin/manager
- **Аутентификация** — Supabase Auth
- **Уведомления** — Telegram Bot API
- **Хостинг** — Vercel (frontend) + Railway (backend, Docker)

## Структура репозитория

```
├── index.html, admin.html      # публичный сайт и админ-панель
├── script.js, admin.js         # клиентская логика
├── style.css, admin.css        # стили
├── config.js                   # публичная конфигурация (Supabase URL/anon key)
├── assets/gallery/              # фотографии
├── vercel.json                  # проксирование /api → бэкенд на Railway
└── backend/
    ├── src/
    │   ├── bookings/            # бронирование, расчёт свободных слотов, предоплата
    │   ├── catalog/              # публичный каталог пакетов/настроек/галереи
    │   ├── admin/                # админ-эндпоинты: заявки, сотрудники (роли admin/manager)
    │   ├── telegram/             # уведомления менеджеру
    │   ├── payments/             # заготовка под онлайн-эквайринг
    │   └── database/             # доступ к Postgres
    └── sql/                      # миграции (роли, цены, предоплата, реквизиты Kaspi)
```

## Запуск локально

```bash
cd backend
cp .env.example .env   # заполнить реальными значениями, PORT=3001 (см. ниже)
npm install
npm run start:dev
```

Фронтенд — статические файлы в корне репозитория, открываются напрямую в браузере
или через любой статический сервер (`npx serve .`); `config.js` сам определяет,
куда слать запросы: `localhost:3001/api` при локальном запуске, `/api` на проде
через Vercel rewrite. Поставьте `PORT=3001` в `backend/.env`, чтобы порт совпал
с тем, что ожидает фронтенд (либо переопределите `window.SVIDANIE_API_BASE_URL`
перед подключением `config.js`).
